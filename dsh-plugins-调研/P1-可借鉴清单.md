### 甲类里最值得先做的 2 个

**1. `Ikalus1988/MisakaNet`（★539）— 唯一「今天就能用」**

零安装，直连公网 MCP：

```json
{
  "permissions": ["mcp.server.remote", "net.fetch"],
  "net": { "domains": ["misakanet.org"] },
  "contributes": {
    "mcpServers": [{
      "id": "misakanet",
      "label": "失败记忆库",
      "transport": "http",
      "url": "https://misakanet.org/mcp"
    }]
  }
}
```

**2. `orziz/odai`（★119）— 补 `local.task-center` 的三块短板**

你现在有 `todo_write`/`todo_read`，但缺 odai 的「目标对齐 → 授权边界 → 真实验收」。它自带 `skills/`，可直接转 `contributes.skills`，再和 task-center 联动。
