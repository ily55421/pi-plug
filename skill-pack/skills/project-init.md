# 项目初始化（移植自 `mcode init` 的 AGENTS.md 生成）

## 首次生成

1. **探查项目**：目录结构、语言/框架（package.json、pyproject、go.mod、Cargo.toml…）、构建与测试命令、lint/格式化配置、README。
2. **用 Read/Glob/Grep 只读采样**，不要执行任意命令。
3. 生成 `AGENTS.md`，按序包含：
   - **一句话项目定位**
   - **常用命令**（构建/测试/lint/单测单文件运行，标注平台：PowerShell 与 bash 各一套，如适用）
   - **架构速览**（关键目录职责，≤10 行）
   - **编码规范**（只写项目实际强制的；从 lint 配置和既有代码归纳，不写通用说教）
   - **验证要求**（完成任务后应运行什么来证明没坏）
   - **禁区**（不要动的目录/文件、外部系统依赖）
4. 全文 ≤120 行，全部祈使句；不确定的内容标注"待确认"而不是编造。

## 增量更新

- 用户说"更新 AGENTS.md"或项目结构变化时：**保留未失效的既有内容**，只增删对应小节；输出变更摘要。
- 禁止整体重写导致用户自定义内容丢失。

## 验收

- 生成后回报：行数、覆盖的命令是否实测可运行（如未执行需注明"未验证"）。
