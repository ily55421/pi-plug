# 可视化页面（移植自 MiniMax Code visual-page 技能方法论）

把内容做成**单文件** HTML 可视化页，无构建步骤、无外部依赖、双击即看。

## 设计规则

1. **单文件自足**：CSS/JS 内联；确需图表库时用 CDN 并注明离线降级（无网时显示数据表格）。
2. **信息层级**：先结论（页面顶部一句话总结 + 关键数字），再分层下钻；不要让读者滚动三次才看到要点。
3. **视觉系统**：
   - 一套主色 + 中性灰阶，最多一个强调色；字号 3 档（标题/正文/辅助）
   - 深浅模式跟随系统：`prefers-color-scheme`
   - 布局用 CSS Grid/Flex，禁止绝对定位堆叠
4. **图表选型**：趋势→折线；对比→条形；构成→堆叠/占比；流程→步骤条；避免 3D、双轴、花哨渐变
5. **数据即代码**：数据以 JSON 内联在 `<script>` 里并命名（如 `const DATA = {...}`），便于后续改数。
6. **响应式**：手机宽度可读；表格横向可滚动。

## 流程

1. 确认数据源与读者要回答的问题（看板给谁、决策什么）。
2. 先在回复里给出 3~5 行的页面结构草案（复杂页面才需要）。
3. 写 `report.html`（或用户指定文件名）到当前工作区。
4. 用浏览器预览工具打开自检一次；把发现的问题修掉再交付。
5. 交付时说明：文件路径、数据截止点、如何改数。

## 边界

- 数据可核实；不虚构数字；缺数据处显示"无数据"而不是 0。
- 不引入框架（React/Vue）除非用户要求。
